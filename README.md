# Как обновлять сайт

Сайт живёт на хостинге **Спринтхост**. GitHub — это только хранилище исходников: правка на GitHub сама на сайт **не попадает**, её надо залить на Спринтхост руками (5 минут).

## Что где лежит

| Где | Что |
|---|---|
| `docs/` | **сам сайт** — ровно то, что лежит на хостинге в `public_html` |
| `docs/index.html` | страница, заголовок и текст превью ссылок |
| `docs/assets/` | дизайн (`style.css`) и логика (`js/`) |
| `docs/data/` | список съёмок (`manifest.json`) |
| `docs/media/` | фото и видео |
| `content/site.json` | контакты, подписи разделов, текст превью ссылок (`role`) |
| `content/meta.json` | названия съёмок, годы, кредиты, порядок |
| `content/brand/logo.svg` | логотип → из него собираются фавикон, иконка для iPhone и картинка превью |
| `tools/build-media.mjs` | сборщик: фото → сайт, иконки, мета-теги |

На Спринтхосте: **Файлы → `domains/milaharys.com/public_html/`**. Там должно быть то же, что в `docs/`: `index.html`, `assets`, `data`, `media`, `favicon.ico`, `favicon.png`, `apple-touch-icon.png`, `og.jpg`. Без вложенной папки `docs`.

## 1. Сделать правку

Через Claude или ChatGPT — дай ему этот репозиторий и скопируй:

> Репозиторий milaharys/me — мой сайт-портфолио, статичный, сайт лежит в папке `docs/`. Прочитай README.md. Хочу: **[что поменять]**. После правки запусти `npm ci && npm run media` (без папки с исходниками фото он только пересоберёт иконки и версию, чтобы у всех обновился кеш) и сохрани изменения в ветку `main`. В конце напиши список файлов в `docs/`, которые изменились.

- Claude Code (claude.ai/code) сам всё сделает и запушит.
- ChatGPT обычно выдаёт готовый код — тогда вставь его на GitHub: открой файл → карандаш ✏️ → вставь → **Commit changes**. В этом случае `npm run media` не запустится: если менялся дизайн (`assets/`), после заливки открой сайт с **Cmd+Shift+R**.
- **Новые съёмки (фото/видео)** — только на своём компьютере: исходники лежат в папке `media-src/` (её нет на GitHub), Claude на компе запускает `npm run media`, сборщик режет фото в `docs/media/` и обновляет `docs/data/manifest.json`.

## 2. Залить на Спринтхост

### Быстро — поменялся текст, дизайн, иконки (без новых фото)

1. Узнай, какие файлы в `docs/` поменялись (ИИ напишет; или на GitHub: вкладка **Commits** → коммит → список файлов).
2. Спринтхост → **Файлы** → `domains/milaharys.com/public_html/` → зайди в нужную папку (например `assets/js`).
3. Зелёная кнопка **загрузить** (стрелка вверх) → выбери новый файл → он заменит старый.

Почти всегда хватает: `index.html`, папок `assets` и `data`.

### Полностью — добавились/удалились фото, или непонятно что менялось

1. GitHub → репозиторий → зелёная кнопка **Code → Download ZIP**.
2. Распакуй. Открой папку `me-main/docs/`, выдели **всё внутри** (Cmd+A) → правый клик → **Сжать**. Получится `Archive.zip`.
3. Спринтхост → **Файлы** → `domains/milaharys.com/public_html/` → отметь верхний чекбокс (всё) → красная кнопка **удалить**.
4. Загрузи `Archive.zip` → отметь его → кнопка **распаковать** (вторая голубая слева).
5. Удали `Archive.zip` и папку `__MACOSX` (мусор от Mac).

Проверка: в `public_html` сразу лежит `index.html`. Если видишь `public_html/docs/index.html` — содержимое `docs` надо вырезать (ножницы) и вставить на уровень выше, а пустую `docs` удалить.

## 3. Проверить

- Открой **milaharys.com** с **Cmd+Shift+R** (жёсткая перезагрузка).
- Сайт без оформления, просто синие ссылки → файлы легли не в корень `public_html` (см. проверку выше).
- Новый фавикон не виден → браузер держит старый: открой сайт в режиме инкогнито.
- Превью ссылки в Telegram старое → отправь `milaharys.com` боту **@WebpageBot**, он обновит.

## Частые правки — что просить у ИИ

- **Текст превью ссылок / заголовок вкладки** → `role` в `content/site.json`, потом `npm run media` пересоберёт `docs/index.html`.
- **Логотип / фавикон** → заменить `content/brand/logo.svg` → `npm run media` → залить `favicon.ico`, `favicon.png`, `apple-touch-icon.png`, `og.jpg`.
- **Контакты** → `content/site.json` + `npm run media`.
- **Названия съёмок, порядок, год** → `content/meta.json` + `npm run media` (на компе с `media-src/`).
- **Шрифты, цвета, отступы** → `docs/assets/style.css`.
