# Как поменять сайт

1. **Правка.** Открой Claude или ChatGPT, загрузи туда файл [`AI-GUIDE.md`](AI-GUIDE.md) и напиши, что хочешь поменять. Он скажет, какие файлы и как править, или поправит сам.
2. **Сохранить на GitHub.** Файл → карандаш ✏️ → вставить новый текст → **Commit changes**.
3. **Залить на хостинг.** Сайт = папка `docs/`. Спринтхост → **Файлы** → `domains/milaharys.com/public_html/` → кнопка загрузки ⬆ → загрузить изменённые файлы **в те же папки, где они лежат в `docs/`** (замена).
   Много изменений или новые фото: GitHub → **Code → Download ZIP** → в `docs/` выдели всё → **Сжать** → в `public_html` удали всё старое → загрузи zip → **Распаковать** → удали zip и `__MACOSX`.
4. **Проверить.** milaharys.com с **Cmd+Shift+R**. Без оформления — значит файлы легли не туда: `index.html` должен лежать прямо в `public_html`, без папки `docs` между ними.
